# 공개 표현 기준 · Public language and design standard

## 원칙 · Principle

이 계정의 public surface는 한국어와 영어를 함께 보여준다. 한국어는 먼저, 영어는 바로 다음에 둔다.  
Every public surface in this account pairs Korean with English. Korean comes first, followed immediately by English.

## 적용 범위 · Applies to

- README headings, descriptions, examples, status labels / README 제목·설명·예제·상태 라벨
- Demo and web UI copy / 데모와 웹 UI 문구
- CLI help, error summaries, and release notes / CLI 도움말·오류 요약·릴리스 노트

코드 식별자, API path, protocol field, shell command, dependency name은 변경하지 않는다.  
Code identifiers, API paths, protocol fields, shell commands, and dependency names stay unchanged.

## 디자인 · Design

- `paper / ink / wine / muted / line` 계열의 차분한 색을 공유한다. / Share the calm `paper / ink / wine / muted / line` palette.
- 상태는 색상만으로 전달하지 않는다. 텍스트와 아이콘을 함께 쓴다. / Never communicate state with color alone; pair color with text and icons.
- 카드와 버튼은 실제 동작으로 연결한다. / Cards and buttons must lead to a real action or an honest status.
- `PROPOSED`, `LIVE DEMO`, `VERIFIED`, `NOT RUN`은 의미를 섞지 않는다. / Do not conflate `PROPOSED`, `LIVE DEMO`, `VERIFIED`, and `NOT RUN`.
